# 覆盖层接入与保存

Strike Her Heart 的运行主体是 Codex 自定义 agent；本文件只说明页面渲染与保存工具。`assets/overlay.js` 是无外部依赖的真实 DOM 覆盖层，运行时不调用远端服务，也不执行 AI 推理。资料理解、工具选择、逐页发现、说明生成与核对由 Codex 中的 agent 完成。

## 接入方式

### 用户有源码的项目

在用户指定的目标项目复制运行时，以项目已有加载方式接入；例如静态页在 `body` 末尾加载本地脚本。SPA 组件卸载调用 `window.StrikeHerHeart.destroy()`。运行时为观察到的当前页面控件建立初始标注；根据项目上下文补充锚点、非标准控件、页签作用域和业务说明。

### 没有源码的在线系统

先确认当前已有的浏览器工具、连接器或站点正式接口是否允许原页覆盖写入。由 agent 选择并使用已有、获授权的执行能力，完成识别、写回和验收。缺少项目源码不等于必须安装浏览器扩展。

如果可用浏览器工具只支持读取，尽早说明缺少哪种原页写入能力，继续完成可独立推进的页面发现、证据和待接入映射。读取页面的截图不等于覆盖层已接入，演示页面通过测试不等于客户系统通过测试。涉及远端原型编辑时使用服务正式能力和用户授权；不能声称修改了第三方原始文件。

### 可选执行器：浏览器扩展

仅在用户对当前任务明确选用此接入方式后，运行 `scripts/build-extension.py --output <新输出目录>` 生成可加载的 Chromium 扩展，再通过浏览器支持的“加载已解压的扩展程序”接入。点击扩展图标，在当前页启用覆盖层；整页导航后要在新页面再次启用。扩展只申请 `activeTab` 与 `scripting`，不默认申请全部站点权限。不要擅自改浏览器安全配置来替代安装。

安装包、扩展图标和侧栏都是这一可选执行器的组成部分；它们不能代替 Codex 自定义 agent 的注册、真实调用和任务编排。用户在 Codex 中继续给地址或按编号修改，agent 负责后续工作，不能把默认流程变成让用户手动维护插件。

扩展包含上海金页面的本地适配 `assets/site-adapters/sge.js`，只在 `quote.fx678.com/exchange/SGE` 启用。它根据当前 DOM 的标题、表头序列和链接目标，为行情表、热力图、展开／收起及原有链接补充说明；目标不唯一时跳过并提示覆盖缺口。气泡编号仍由运行时在真实目标上生成，人工修改沿用原有保存保护。适配测试使用模拟页面，只证明实现行为；正式页面仍需安装后逐项核验。

具体标题出现同名歧义时，如果行情表与热力图均唯一，且存在同时包含两表的可见、非 `body/html` 主内容容器，页面总说明可以锚定该主内容区；字段和覆盖提示会明确说明未唯一定位具体标题。该处理不选择任意同名标题，也不读取或保存容器内的聚合报价。缺少任一表或只有整页根容器时继续报告缺口。新增页面目标追加编号，已有编号及人工修订保留。

通过电脑操作工具加载未上架的本地扩展时，遵守该工具的动作时确认要求：先完成可审阅的包与验证，再请求安装确认。用户确认前不加载、不以书签脚本或其他注入路径绕过同一边界。

### 演示

`assets/demo.html` 为明确标识的虚构业务页面，直接加载同目录运行时。用于检查气泡、右栏编辑与页面交互。没有用户系统地址时，可以交付此可操作演示并说明尚未接入具体目标。

### 截图／画板输入

随附运行时扫描 DOM，不能自动从一张图片提取并定位内部控件。只有图片时，agent 先实际查看图片并完成控件区域核读，再为该任务制作图片适配预览：以用户提供的原图为背景，以 `{imageId, version, naturalWidth, naturalHeight, region:[x,y,width,height]}` 保存归一化锚点；按实际显示矩形与缩放／平移偏移换算气泡与连接线。背景图片不重画，右侧详情按同样的四项字段、证据、编号、编辑保存和多项打开规则实现。多张图按原页面与状态切换，未提供的弹窗保持缺口。

这是收到实际图片后要完成并验证的任务适配，不是当前 DOM 运行时已经实现的图像识别功能。不能把此演示页或未经核对的自动图片坐标作为图片标注完成的证据。

## API 与 AI 说明合并

页面源码直接接入时，`window.StrikeHerHeart` 提供：

```js
const snapshot = window.StrikeHerHeart.getSnapshot();
window.StrikeHerHeart.scan();
const data = window.StrikeHerHeart.exportData();
// 阅读真实资料后，按返回的页面 scope 与原编号合并说明。
window.StrikeHerHeart.importData(data);
window.StrikeHerHeart.toggleDrawer(false); // 只收起详情，保留页面气泡。
window.StrikeHerHeart.toggle();
window.StrikeHerHeart.destroy();
```

扩展运行在隔离环境，普通页面 JS 不一定能访问该对象；使用覆盖层自带的 JSON 导出／导入 UI 交换数据。浏览器工具允许的读取／操作方式以当前工具文档为准，不为调用 API 绕过注入限制。

视口宽度不超过 1100px 时，右侧详情默认收起，原页编号气泡继续显示；点击气泡打开详情，使用“收起详情面板，保留页面编号气泡”按钮可返回原页操作。收起不会删除打开记录、草稿或已保存文字。“隐藏全部标注”则连同气泡一起隐藏，两种操作分开。`getSnapshot().ui.drawerOpen` 和 `narrow` 可用于验收当前展示状态。

右栏的“查找标注”入口在已打开详情时仍可使用，支持 `A-009`、`9` 和控件名称，按待确认、冲突／待复核、人工修改或证据层级筛选当前目标。选择目录项仅定位目标并打开说明，不触发目标的业务点击。四项核心说明直接可编辑，来源依据在每字段下按需展开。

`getSnapshot().ui.quality` 提供当前目标中的总项数、包含待确认字段的项数、需复核项数、人工修改项数、未保存项数和暂未摆放气泡数。同一项可以同时属于多个状态；这些是当前呈现范围的项数，不是字段总数、整站覆盖率或业务理解完成率。页面／状态切换后只统计当前目标。

人工输入不会自动解除已有 `conflict`／`review` 状态。核对实际依据后明确调整字段状态，才表示处理了该冲突；人工修改记录仍单独保留。保存写入失败时，不提交本次说明与修订、不清除草稿，并显示失败与重试入口；恢复存储后保存成功，再通过实际刷新确认。未保存草稿仅在当前会话中，普通导出不包含这些草稿。

### 字段证据分级

每个字段旁显示带文字与等级编号的徽标：**L1 已实测、L2 页面声明、L3 PRD 依据、L4 模型猜测、未分级**，
颜色仅作辅助。PRD 区分直接定义和推断；徽标与确认状态同时显示。展开来源区可编辑等级、来源、
定位、实际动作、观察结果和时间，原有依据文本仍保留。

每条标注新增 `evidenceMeta`，其 `content/function/limits/navigation` 各自使用以下形状：

```js
annotation.evidenceMeta.limits = {
  level: 'page', // tested | page | prd | guess | unclassified
  source: '当前 DOM',
  locator: '#customer-name',
  action: '', result: '', observedAt: '',
  derivation: 'explicit' // PRD 时区分 explicit / inferred
};
```

自动扫描的 DOM 属性与链接归 L2，不声称实测；无来源说明保持未分级。L1 必须给完整的来源、
定位、动作、结果与 ISO 时间，L2／L3 必须给来源和定位。编辑表单缺项时保存失败并保留草稿；
外部导入的无效等级记录降为未分级并待复核。仅结构校验通过不能证明操作真实发生。

L4 保持待确认；已有 conflict/review 不会被降低等级覆盖。L1 正文变更时保留原来源，但新文字
进入复核。等级、文档版本或其他结构化依据的变化与文字差异一样参与人工保护、导入建议、
修订历史及保存回滚；不能只因为正文相同就静默替换人工维护的依据。

旧版本的 observed 只迁移为页面声明，其余无法判定来源的旧记录保留未分级。保留 schemaVersion=1
和既有编号、存储键；`evidence` 与 `fieldStates` 仍保留。没有 `evidenceMeta` 的旧版消费者可以
继续读取原字段，但不会显示新等级。完整分级语义见 [信息与证据](annotation-evidence.md)。

`getSnapshot().ui.evidenceSummary` 按当前可见目标的四个字段分别统计 tested/page/prd/guess/unclassified
数量；它统计字段，原 `ui.quality` 仍统计标注项，两者不能当成整站覆盖率或说明准确率。

气泡按实际尺寸避开业务控件、其他气泡及已展开侧栏，仍用连接线指向目标。若拥挤布局中确实找不到安全空位，`ui.placementHiddenIds` 会列出暂时无法摆放的气泡；需要通过目标适配补齐，不能把详情目录有记录当作原页气泡已完成。

扩展通常通过点击导航、路由事件和 DOM 变化触发重扫。主页面若仅用程序化 `pushState` 切换地址且没有任何 DOM 变化，隔离环境可能收不到变化，应使用“重新识别”或由正式集成主动触发 `scan()`；在该目标系统验证后才能声称其全部路由自动跟随。

导出结构包含 `schemaVersion`、`agent`、`exportedAt`、`pages`；每页有 `scope`、`annotations` 和 `coverage`。`displayId` 为 `A-001` 式人可读编号，`id` 是内部稳定键；口述修改按当前页面与 `displayId` 查找，跨页同号时连同页面定位。沿用导出的对象形状，**按原 `scope`、`id`、`anchor` 修改说明，不能重新编号或伪造目标锚点**。字段为 `content`（内容）、`function`（功能）、`limits`（限制）、`navigation`（跳转）；`evidence` 保留依据文本，`evidenceMeta` 保留结构化分级及来源，`fieldStates` 保留独立确认状态；`revisions` 记录修订。实际约束以运行时返回的结构和校验为准。

导入必须保留人工编辑。agent 对已编辑字段产生不同建议时，先展示差异或标待复核，不抹掉人工内容。一次导入后重新打开相应气泡，核对文字、依据、状态与修订；不能只验证 JSON 语法。

“采用建议为草稿”在成功保存后才移除原建议；撤销草稿或写入失败时保留候选与结构化来源。
导入写入失败会恢复导入前的页面、字段、来源、修订与缓存，并抛出明确错误；不得将失败报告为已导入。

### 覆盖层还未接入时继续做什么

先在本次任务的标注数据中建立“待接入映射”：页面／状态、资料中的控件键、目标可见名称与上下文、可读取的稳定属性或截图区域、四项说明、字段依据、当前对应状态。不为尚未运行的覆盖层伪造正式编号、`scope` 或 `anchor`；临时资料键仅用于追踪。此数据是未完成接入的中间结果，不能作为最终页面标注替代品。

接入后导出真实扫描结果，按页面／状态、稳定属性、可见名称与父级上下文共同核对，记录“临时资料键 → 运行时编号／锚点”的映射，再导入有唯一对应的说明。多个同名候选保持待定位；无法核实的旧坐标不直接复用。人工修订跟随已核对的控件映射迁移，保留旧来源与修订轨迹。重新检查原页显示后，才把相关页面由待接入改为已标注。

## 自动识别范围

运行时扫描可见原生控件和常用 ARIA 控件，记录标签、种类、声明的约束与链接信息，不读取输入值或密码。非标准交互、跨域 iframe、封闭 Shadow DOM、Canvas 和虚拟化内容需要目标项目的适配或原画面定位；`coverage` 提示不能代替实际检查。隐藏面板、未打开菜单、未访问页面不算已覆盖。

页面作用域剔除 URL 查询参数等可能敏感的部分。因此依靠 query 切换业务页面的系统需要由项目集成提供明确页面映射或进一步适配，未经核对不能复用锚点。稳定属性优先于 DOM 位置；纯位置锚点在结构变化后必须复核。完整页面跳转需重新启用扩展覆盖层。

## 保存

Codex agent 的任务清单、证据、控件与实际编号映射、备份及未完成项保存在工作区；页面标注的保存范围由具体执行器决定。下面的 localStorage 行为只适用于随附 DOM 运行时。

该运行时默认 localStorage 保存属于当前浏览器、站点来源的标注，包含用户编辑、依据和修订，不含原表单输入值。页面脚本能访问同源 localStorage；需要更强隔离时按目标环境使用扩展存储或项目正式数据层。运行时没有自动上传和跨设备同步，JSON 是备份及 agent 说明合并方式。不要把私有系统的标注导出提交到公共版本库。

一次导出只包括该次运行中已经载入缓存的页面记录；整页跳转前的其他页面不保证自动收集。agent 每完成一个页面／状态，应将该范围的实际导出和检查结果保存至私有任务证据目录，再通过 [任务记录工具](task-workflow.md) 关联稳定页面 ID。任务清单补足跨页面续接，不改变浏览器存储的实际范围。

无存储权限、容量不足或导入校验失败时保留草稿，明确提示失败。更新运行时、资料或版本时保留导出备份与既有编号；通过实际刷新和切页验证保存，而非从代码推测。
