## 复核与重算

- [候选原始输出](predictions.json)：实际 agent 写出的冻结内容。
- [独立评审](review.json)：与候选及数据集摘要绑定，包含全文逐段判定。
- [JSON 报告](report.json)、[Markdown 报告](report.md)：每个样本、分母、遗漏与门槛。
- [运行来源记录](run.json)：调度方式、输入摘要、观察方式和限制；评分器本身不认证 agent 执行。
- [引用修订审计](reference-audit.json)：v1.0.1 只补全 13 条事实的来源引用，所有评分要求与评审标签保持不变。
- [初始 v1.0.0 数据集](initial-reference-1.0.0/dataset.json) 与 [初始评审](initial-review-1.0.0/review.json)：保留最初冻结版本，可独立重算。

在仓库根目录执行：

```bash
python3 scripts/evaluate.py \
  --predictions evals/results/2026-10-27-run-01/predictions.json \
  --review evals/results/2026-10-27-run-01/review.json \
  --output /tmp/shh-baseline-recomputed.json --strict
```

命令应生成同样指标，并因未达到开发门槛返回退出码 **1**；这不是程序错误。去掉 `--strict`
可以只生成报告。重算初始版本时，将 `--dataset` 指向本目录的
`initial-reference-1.0.0/dataset.json`，将 `--review` 指向 `initial-review-1.0.0/review.json`。

重算不调用模型，不等于重新运行 agent。新候选必须重新准备输入、实际调度、冻结输出并独立评审。
