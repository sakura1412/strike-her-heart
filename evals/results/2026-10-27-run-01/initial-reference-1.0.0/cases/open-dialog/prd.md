# 邀请成员弹窗 PRD

## 当前状态
页面加载后邀请成员弹窗已打开。本次范围仅为该弹窗内当前四个可操作控件；背景 inert 区域不纳入。关闭后的页面不属于本次状态，不需要扩大遍历范围。

## 成员邮箱
必填，按浏览器 email 输入校验接收单个邮箱，不支持多个收件人。未指定长度上限或允许域名列表。

## 成员角色
可选查看者或编辑者，初始为查看者。角色在这里是邀请目标成员的角色，不是当前操作者的权限证明。

## 发送与取消
发送邀请先进行浏览器表单校验，通过后在弹窗内显示本地反馈；不发送邮件、不请求服务器，不关闭弹窗，不跳转。
取消关闭当前弹窗返回同页背景，不提交或清空已填值；刷新页面后恢复初始值。
